Where this comes from

A prototype by NSBE RIT Chapter #103 for Imagine RIT. Not commercial, and not affiliated with the national organisation. This page says where each piece of it came from, what licence it is under, and what nobody has checked yet.

Short version. The map itself is built from open data (OpenStreetMap) and open-source software. No Google imagery. The tunnel layout is a schematic and is not accurate to RIT's current tunnels. Three things still need someone's permission or confirmation; they are marked below.

Data and software

Buildings and footpaths — OpenStreetMap

Open licence ODbL 1.0 · retrieved through the Overpass API · 277 building footprints, plus footpaths for outdoor routes.

The attribution on the map is a condition of the licence. It stays.

Base map — OpenFreeMap

Open licence OpenMapTiles schema (CC-BY 4.0) over OpenStreetMap data (ODbL) · no account or API key.

Rendering — MapLibre GL JS 5.6.1

Open licence BSD 3-Clause.

Typeface — Geist

Open licence SIL Open Font Licence 1.1, served through Google Fonts.

Not yet confirmed

WITR 89.7 live stream

Ask WITR The map plays the station's public stream in the browser. It does not record, copy or rehost it. WITR has not been asked, and should be.

The NSBE and RIT marks

Confirm with the chapter and RIT The map uses the RIT NSBE chapter logo, supplied by the chapter, and the RIT wordmark. They are trademarks of their owners and are used here with the chapter's involvement. This is a prototype; any wider use should be cleared with RIT.

The routing graph

Schematic 40 waypoints and 49 edges (data/campus.json). Not surveyed. How the coordinates were first obtained has not been written down and should be.

Deliberately not used

RIT floor plans and tunnel plans

Restricted RIT Facilities Management keeps these behind an RIT login. They were not scraped and are not in this project. Accurate tunnels need Facilities Management's agreement.

Google satellite imagery

Removed An earlier version of this project loaded Google satellite tiles and used screenshots of them. That has been removed from the site and the repository.

Original work

The Ritchie balloon, the tiger marker, the cloud sequence and the tunnel animation are drawn in code by this project. Ritchie is RIT's mascot, so his likeness belongs to RIT.
